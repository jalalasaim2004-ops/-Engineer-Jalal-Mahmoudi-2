## 📌 Overview
This is a modern, high-performance personal portfolio built with cutting-edge web technologies. It features a professional "Deep Slate" dark-mode aesthetic, sleek glassmorphism UI, smooth scroll animations, and interactive 3D elements to showcase engineering and AI expertise.

## 🛠️ Tech Stack
- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics:** [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/)
- **Deployment:** GitHub Pages

## ✨ Features
- **Responsive Design:** Perfectly scales across desktops, tablets, and mobile devices.
- **Glassmorphism UI:** Premium frosted-glass effects with neon glow accents.
- **Interactive 3D Elements:** Engaging background meshes powered by WebGL.
- **Dynamic Projects Showcase:** Filterable project cards with 3D-tilt mouse tracking.
- **RTL Support:** Full Right-To-Left layout tailored for Arabic typography.

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (version 18+ recommended) installed on your machine.

### Installation & Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/jalalasaim2004-ops/-Engineer-Jalal-Mahmoudi-2.git
   ```
2. Navigate to the project directory:
   ```bash
   cd -Engineer-Jalal-Mahmoudi-2
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to `http://localhost:5173`.

## 📦 Deployment
This project is configured for one-click deployment to GitHub Pages.

To build and deploy a new version, simply run:
```bash
npm run deploy
```
*(This command will automatically run `vite build` and push the `dist` folder to the `gh-pages` branch).*
